# homebrew-tap

Homebrew tap for [**hauntty**](https://github.com/winterweken/hauntty) — a TUI theme
& settings manager for the [Ghostty](https://ghostty.org) terminal.

## Install

```sh
brew install winterweken/tap/hauntty
```

Or tap first, then install:

```sh
brew tap winterweken/tap
brew install hauntty
```

## Upgrade

```sh
brew update
brew upgrade hauntty
```

## Formulae

| Formula | Description |
|---------|-------------|
| `hauntty` | TUI theme & settings manager for Ghostty |
